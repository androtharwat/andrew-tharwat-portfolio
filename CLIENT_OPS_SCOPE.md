# ANDREW THARWAT STUDIO V9 — Client Operations Scope

Branch: `v9-client-ops`

This branch is the isolated development branch for the operational layer of Andrew Tharwat Studio V9.

## Owned here

- Studio OS / admin operations dashboard
- Leads and qualification
- Proposals and client conversion
- Clients
- Projects / Project Workspace
- Payments tracking
- Files, revisions and approvals
- Client Portal
- Client-operations database schema and RLS when explicitly introduced

## Not owned here

Public V9 website design and content remains on `v9-development`.

Do not use this branch for unrelated public-site visual changes.

## Integration rule

Public V9 and Client Operations are developed independently and merged only after each side is stable and reviewed.
